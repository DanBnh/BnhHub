# BnhHub

Projeto existente do BnhHub com identidade verde/neon e mascote raposa.

## Gerenciador de conteúdo

Abra **Configurações → Gerenciar conteúdo** para:
- editar/remover/adicionar Ferramentas;
- editar/remover/adicionar Sites;
- editar/remover/adicionar canais do YouTube;
- trocar logos por URL ou arquivo local;
- adicionar, editar e remover artes do Portfolio;
- definir curtidas fictícias para cada nova arte do Portfolio.

As alterações são salvas no `localStorage` do navegador. Imagens enviadas pelo usuário ficam armazenadas localmente no navegador, com limite de 5 MB por arquivo.
